# Translate a PowerPoint deck

:::info Verification environment

The steps on this page were verified in the following environment.

- **Kari**: version 0.5.0 Beta
- **AI provider**: standalone OumiGo (version 0.3.0)
- **GPU**: A40
- **LLM**: Google Gemma 4 31B IT (quantized by Google, Hugging Face repository: `google/gemma-4-31B-it-qat-w4a16-ct`)

:::

With Kari you can translate a PowerPoint deck on your machine into another language. The PPTX format is supported.

## Check the input

- In Kari's Explorer, open the folder that holds the file, then click the file to display its contents.  
The PPTX used in this example is the training material for young employees and university students (「若年層向け（若手社員・大学生向け）」), PPTX version (`training_young2023.pptx`), from the downloads page (「資料ダウンロード」) of the Ministry of Health, Labour and Welfare's Ikumen Project website. Here it is saved in the `Files` folder.  
URL: https://ikumen-project.mhlw.go.jp/library/training/

## Instruct the AI

- Create a new chat session and enter "Translate this PPTX file into English and save it as the file 'Files/training_young2023_en.pptx'." in the input box. The screenshot shows the same request in Japanese.

![Asking the AI to translate the PPTX file](@site/docs/current/main/usekari/img/usekari_translatepptxinstruction.png)

*Screenshot shown in the original Japanese.*

## Check the AI's output

- The AI saves the translated file in the local folder. Open the file and review the result.
