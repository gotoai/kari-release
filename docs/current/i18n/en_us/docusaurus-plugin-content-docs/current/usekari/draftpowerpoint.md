# Draft a PowerPoint deck

:::info Verification environment

The steps on this page were verified in the following environment.

- **Kari**: version 0.5.0 Beta
- **AI provider**: standalone OumiGo (version 0.3.0)
- **GPU**: A40
- **LLM**: Google Gemma 4 31B IT (quantized by Google, Hugging Face repository: `google/gemma-4-31B-it-qat-w4a16-ct`)

:::

With Kari you can draft a PowerPoint deck. The output is a file in PPTX format.

## Check the input

- From the House of Representatives website, open the list of questions and answers for the 221st Diet session (「第221回国会　質問の一覧」).  
URL: https://www.shugiin.go.jp/internet/itdb_shitsumon.nsf/html/shitsumon/menu_m.htm

![List of questions and answers on the House of Representatives website](@site/docs/current/main/usekari/img/usekari_weblist.png)

*Screenshot shown in the original Japanese.*

- Open the HTML answer (「答弁(HTML)」) for item number 2, the question on fiscal resources (「財源に関する質問主意書」), and confirm that the content is readable.  
URL: https://www.shugiin.go.jp/internet/itdb_shitsumon.nsf/html/shitsumon/b221002.htm

![The answer page on the House of Representatives website](@site/docs/current/main/usekari/img/usekari_webpage.png)

*Screenshot shown in the original Japanese.*

## Instruct the AI

- Enter the URL of the answer page in the session's input box and ask the AI to build an outline deck. An example prompt follows; the screenshot shows the same prompt in Japanese.

> Structure the content of the answer on this page, " https://www.shugiin.go.jp/internet/itdb_shitsumon.nsf/html/shitsumon/b221002.htm ", create a PowerPoint deck outlining the answer, and save it as the file "答弁骨子.pptx".
>
> Organize the information in at most three levels: heading 1, heading 2 and body text. Use the following font sizes:
>
> - Deck title: 36 pt  
> - Message line: 28 pt  
> - Heading 1: 20 pt  
> - Heading 2: 16 pt  
> - Body text: 12 pt

![Asking the AI to create the PowerPoint deck](@site/docs/current/main/usekari/img/usekari_draftpptxinstruction.png)

*Screenshot shown in the original Japanese.*
