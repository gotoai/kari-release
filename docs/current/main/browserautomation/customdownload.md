# データを自動ダウンロードし、規定ファイル名で保存する

:::info 検証環境

本ページの手順は、以下の環境で動作を確認しています。

- **Kari**: バージョン 0.6.0 Windows
- **AI プロバイダー**: Anthropic Claude サブスクリプション
- **モデル**: Anthropic Opus 5 (1M)

:::

## ユースケースの説明
ウェブサイトからファイルを1件ずつ手動でダウンロードした経験がありませんか。多くの場合は、Web API は用意されず、社内システムであったり、サインインが必要であったりするため、Web スクレイピングすることはできず、やむを得ず時間を費やして手動作業でデータをダウンロードします。

しかも、元のファイル名が目的に合わず、手動で変更しなければならない場合もあります。ダウンロードするファイル数が多くなると、処理漏れ・変更ミスなどのヒューマンエラーのリスクが高まります。  

Kari の Browser 処理自動化の機能を活用すれば、このような作業は簡単に AI エージェントに依頼できます。本事例では、オープンサイトを用いて説明しますが、その手順はクローズドサイトでも適用できます。

## シナリオ
ユーザーは、観光庁「インバウンド消費動向調査」のページから、直近3年分の Excel 集計データを網羅的にダウンロードし、規定のファイル名で保存します。AI エージェントを活用すると、下記のメリットがあります。

- 対象ファイル数が20件以上で、かつ Excel・PDF ファイルが混在するため、AI エージェントを活用すると作業ミスのリスクを低減できます。
- 元のファイル名は内容を表しておらず、意味の分かる名前に変更したいという要望があります。AI エージェントは、意図のとおりにファイル名を自動処理できるので、手間を省き、作業ミスを防げます。
- AI エージェントが作業する間に、ユーザーが別の作業をすることができるので、結果的に効率が上がります。

## 作業の準備

- 保存先となる作業フォルダーを決めます。左のナビパネルの「エクスプローラー」を右クリックし、「フォルダーを開く…」から指定します。ダウンロードしたファイルはこのフォルダーに保存されるため、書き込み権限のあるフォルダーを選んでください。

- 左のナビパネルの「Web ブラウザ」を開き、対象のページを表示します。  
URL: https://www.mlit.go.jp/kankocho/tokei_hakusyo/gaikokujinshohidoko.html

![観光庁 インバウンド消費動向調査のページ](@site/docs/current/main/browserautomation/img/download_jta.png)

- ページを下へスクロールし、これから取得する対象を目で確認しておきます。このページでは「調査結果」の見出しの下に年（2026年・2025年・2024年…）の小見出しがあり、その配下に「4-6月期 集計表（1次速報）」「2025年年間 集計表」「1-3月期 【参考】都道府県別集計表」のようなリンクが並んでいます。  
**リンクのテキストには年が入っているものと入っていないものが混在している**ため、年はページの構造（年の小見出し）から補う必要があります。これが後述のファイル名ルールの要点になります。

:::tip

サインインが必要な社内システムやクローズドサイトの場合も、Kari の Web ブラウザで先にサインインしておけば、同じ手順でそのセッションのまま AI に操作を任せられます。

:::

## AI に作業を指示

- 対象の絞り込み、保存ファイル名の規則、アクセス上の遵守事項をまとめて、以下のように AI に作業を指示します。

> 現在開いている観光庁「インバウンス消費動向調査」のページから、Excelの集計表をダウンロードし、規定ファイル名形式で保存してください。
>
> 0. アクセス上の遵守事項  
> (1) ページ遷移の間隔は1秒以上空け、同時並行のリクエストは行わないでください。  
> (2) CAPTCHA、アクセス制限、エラー画面が表示された場合は、回避を試みず作業を中断し、その旨を報告してください。
>
> 1. 作業方針  
> (1) Browserツールを使用し、Web Fetchツールは使わないこと。  
> (2) ダウンロード以外の書き込み操作はしないこと。  
> (3) 対象は「xx-xx月期 集計表」、「xx年間 集計表」、「xx 都道府県別集計表」のExcelのみ。  
> (4) 直近3年分（年間＋四半期）に限る。
>
> 2. ファイル保存  
> (1) 今のセッションフォルダーで保存する。  
> (2) 保存ファイル名はダウンロードリンクのテキストをもとに、期間を示す数字から「集計表」までの部分を抽出し、さらにページの構造からデータの所在年を抽出し、テキストの先頭に追加。例：  
> 　・「2024年10-12月期 集計表」  
> 　・「2024年年間 集計表」  
> 　・「2024年10-12月期 【参考】都道府県別集計表」  
> 　・「2024年年間 【参考】都道府県集計表」  
> 　・「2026年4-6月期 集計表（1次速報）」  
> 　・「2026年1-3月期 【参考】都道府県別集計表」  
> (3) 拡張子は元ファイルのまま保持。
>
> 3. チャット出力；ファイル保存に加え、チャットの返信本文に、箇条書き＋表で出力  
> (1) 保存したファイルの一覧表：新ファイル名／元ID／リンク表示名／ファイルサイズ／取得元URL。  
> (2) ダウンロードできなかったもの、命名を判断できなかったものがあれば明記。  
> (3) 出典を明記（出典：国土交通省ウェブサイト、該当ページURL）。

![AI にダウンロード作業を指示する](@site/docs/current/main/browserautomation/img/download_jta_prompt.png)

この指示の組み立て方には、次のポイントがあります。

| 指示のブロック | ねらい |
| --- | --- |
| 0. アクセス上の遵守事項 | 相手サイトに負荷をかけないよう、間隔と直列実行を明示します。CAPTCHA やエラー画面に遭遇したら**回避せず中断して報告**させることで、意図しない迂回操作を防ぎます。 |
| 1. 作業方針 | 使うツールを Browser に限定し、取得対象を「集計表の Excel のみ」「直近3年分」に絞ります。これにより、報告書 PDF や概要 PDF を除外できます。 |
| 2. ファイル保存 | リンクのテキストから取り出す範囲（期間の数字から「集計表」まで）と、ページ構造から補う年を分けて定義し、例を6件示します。**例を複数挙げること**で、「年間」「【参考】都道府県別」「（1次速報）」といった変則パターンの扱いが安定します。 |
| 3. チャット出力 | 保存結果を表で報告させ、さらに**できなかったものを明記**させます。人の確認作業がここに集約されます。 |

:::caution

「ダウンロード以外の書き込み操作はしないこと」のように、AI に**許可する操作の範囲**を明示してください。フォームの送信や設定変更など、意図しない書き込み操作を避けられます。

:::

## AI の作業結果を確認

- AI はページ全体のリンクを読み取って対象を整理し、取得件数を報告してから、1件ずつダウンロードを実行します。処理中はツールの実行状況がセッションウィンドウに表示されます。

![AI がダウンロードを実行している様子](@site/docs/current/main/browserautomation/img/download_jta_aiprocessing.png)

- 作業が終わると、実行結果のサマリーが表示されます。対象の絞り込み方、取得件数、リクエストの間隔が報告されます。

![AI の実行結果サマリー](@site/docs/current/main/browserautomation/img/download_jta_result.png)

この例では、次のことが報告されています。

- Excel の集計表のみ（報告書・概要 PDF、分析 PDF は除外）を抽出し、直近3年分＝2026年・2025年・2024年の計23件をダウンロードした。
- リクエストは1件ずつ直列で実行し、各取得の間に1.5秒以上の待機を挟んだ。CAPTCHA・アクセス制限・エラー画面は発生していない。
- 全ファイルのバイナリ署名を検証済み（`.xls` は OLE2、`.xlsx` は ZIP）。HTML のエラーページがファイルとして紛れ込んでいないことを確認した。

- 保存ファイルの一覧表がチャット本文に出力されます。「新ファイル名」「元ID」「リンク表示名」「サイズ」「取得元URL」の各列で、**どのリンクがどのファイル名になったか**を1行ずつ追跡できます。

![保存ファイル一覧の表](@site/docs/current/main/browserautomation/img/download_jta_result2.png)

- 左のエクスプローラーで、実際に保存されたファイル名を確認します。リンクのテキストに年がなかったものにも、ページ構造から読み取った年が先頭に補われています。

| リンク表示名（ページ上） | 保存されたファイル名 |
| --- | --- |
| 4-6月期 集計表（1次速報） | `2026年4-6月期 集計表（1次速報）.xlsx` |
| 1-3月期 【参考】都道府県別集計表 | `2026年1-3月期 【参考】都道府県別集計表.xlsx` |
| 2025年年間 集計表 | `2025年年間 集計表.xls` |
| 10-12月期 【参考】都道府県別集計表 | `2025年10-12月期 【参考】都道府県別集計表.xlsx` |

- 一覧表の「取得元URL」をいくつか開き、ファイルサイズが元のページの表示（例：`[Excel:734KB]`）と一致していることを確認します。

## Human-in-the-loop のポイント

AI に任せきりにせず、次の点は人が確認してください。

- **保存先を事前に確認する**  
AI に作業を依頼する前に保存先を用意してください。AI の書き込み権限は Kari の実行アカウントと同じです。保存先に書き込めること、そして作業の後に実際にどこへ保存されたかを確認してください。

- **件数を突き合わせる**  
「直近3年分」のような相対的な条件は、ページの更新によって対象が変わります。AI が報告した件数（本例では2026年3件・2025年10件・2024年10件の計23件）と、ページ上の掲載状況を照らし合わせてください。

- **ファイル名の「年」の根拠を確認する**  
年はリンクのテキストではなく、ページの構造（年の小見出し）から推定しています。年をまたぐ四半期や、見出しの構造が異なるページでは、推定を誤る可能性があります。年の境目にあたるファイル（1-3月期、10-12月期など）を優先して抜き取り確認してください。

- **エラーが発生した場合は AI の報告を読む**  
指示の「ダウンロードできなかったもの、命名を判断できなかったものがあれば明記」に対する回答を必ず読んでください。**何件取れたか**より、**何が取れなかったか**のほうが重要です。

- **中身が本当に Excel ファイルであることを確認する**  
アクセス制限がかかると、Excel のかわりに HTML のエラーページが同じファイル名で保存されることがあります。本例のようにバイナリ署名の検証を依頼するか、保存後に数件を実際に開いて確認してください。

- **相手サイトの利用条件を守る**  
アクセス間隔や同時実行数の指定は、依頼する側の責任です。対象サイトの利用規約・`robots.txt` を確認し、取得したデータの二次利用が許されているかを判断してください。

:::caution

使用する LLM により、読み取りの精度や出力の体裁が変わることがあります。件数の多い一覧は、元のページと突き合わせて確認してください。

:::
