# MCP サーバー

MCP サーバーは、デスクエージェントが**外部のデータや外部システムを活用する経路**です。業務に固有のデータソース、社内システム、公的機関の API などが、これにあたります。

[スキル](./skills.md)との役割分担は、**MCP サーバーがツール、スキルが手順**です。本書の例2では、EDINET（金融庁）から有価証券報告書を取得する MCP サーバーがツールにあたり、取得した報告書をどう読んで何と比べるかを書いたものがスキルにあたります。

## デスクで MCP サーバーを選択する

設定ウィンドウの「MCP サーバー」には、**Kari に設定済みの MCP サーバー**が一覧で並び、それぞれにスイッチが付いているだけです。ここでサーバーを追加したり、接続先を書き換えたりはできません。

![MCP サーバー選択画面](@site/docs/current/main/agentdesk/img/agentdesks_settings_mcp_edinet.png)

<div className="caption">MCP サーバー選択画面</div>

:::note
サーバーの追加と設定は、Kari 本体の「MCP サーバー」画面で行います。デスク側は「このデスクにどれを使わせるか」だけを決めます。

MCP サーバーを Kari 本体で設定していないと、この画面には何も表示されません。Kari 本体の「MCP サーバー」画面から追加すると、デスク側で有効にできるようになります。

:::

## エージェントデスクでの MCP サーバー制御はデスク単位です

一覧には、**Kari 本体でオフにしているサーバーも並びます。** 有効・無効は、Kari 本体や他のデスクとは独立して、デスクごとに管理されます。

:::note

[設定情報をエクスポート](./introduction.md#設定情報のエクスポートとインポート)したデスクを別のパソコンに取り込むと、MCP サーバーは**名前のまま**引き継がれます。取り込んだ側の Kari に同じ名前のサーバーが設定されていない場合は、Kari 本体の「MCP サーバー」画面で設定を済ませてください。

:::

## 本書の説明事例で使うサーバー

| 事例 | MCP サーバー | 役割 |
| --- | --- | --- |
| 例1：補助金診断デスク | Jグランツ（jGrants）の MCP サーバー | 補助金・助成金の公募情報の検索と、公募要領の閲覧 |
| 例2：企業業績診断デスク | EDINET（金融庁）の MCP サーバー | 有価証券報告書の一覧取得と、報告書本文の取得 |

いずれも Kari に同梱の Python 環境にインストールして使う、Python パッケージ形式のサーバーです。導入の手順は、各事例のページで説明します。

:::caution APIキー情報はエクスポート・インポートしません

MCP サーバーが必要とする API キーなどの情報は、セキュリティ考慮のため、**名前で参照する形で登録され、設定ファイルに直接書き込まれません。** インポートした後、設定の引継ぎ側でもう一度キーを入力する必要があります。

:::
