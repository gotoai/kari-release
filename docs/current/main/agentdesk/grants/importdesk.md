# デスク設定のインポート

## この事例について

**補助金診断デスク**は、対象企業の情報から申請候補になりうる補助金を探し、**PDF の診断レポート**を作って依頼者に届けるエージェントデスクです。

| | 内容 |
| --- | --- |
| 依頼者が出す情報 | 対象企業名とホームページURL、主たる業種、従業員数、補助金を充てたい経費の区分（想定用途）、想定投資額、結果を受け取るEメールアドレス |
| デスクが使う情報 | 対象企業のホームページと、Jグランツ（jGrants）で受付中の補助金の公募情報・公募要領 |
| デスクが返すもの | 候補の補助金とその適合性をまとめた診断レポート（PDF）。ダウンロードポータルとEメール添付で届きます |
| 所要時間の目安 | 依頼1件あたり数分〜十数分（AI プロバイダーと候補の数によります） |

このデスクは、[MCP サーバー](../mcpservers.md)が1つ、[スキル](../skills.md)が1つという最小の構成です。設定済みのデスクをインポートして動かすので、フォームやスキルを一から作る必要はありません。

:::caution 申請の代行ではありません

本デスクが作るレポートは、公開情報をもとに申請できそうな補助金を探す**分析**であり、申請の代行や行政書士業務ではありません。**対象かどうかの最終的な判断は、各補助金の事務局によるもの**です。申請の前に、必ず公募要領と公式の掲載ページで確認してください。

デスク全体指示とスキルにも、対象可否を断定せず、確かめるべき点は「要確認」として残すことを明記してあります。

:::

## 必要なもの

- **Kari 0.7.4 以降。**
- **API キー方式の AI プロバイダー。** デスクはサブスクリプションでは動きません（[その他設定](../othersettings.md#ai-プロバイダー)）。
- **SMTP で送信できるEメールアカウント。** Gmail、または SMTP サーバーのあるメールボックス。

:::note MCP サーバーの API キーは不要です

このデスクが使う Jグランツの MCP サーバーは、公開 API を使うため API キーの登録がいりません。[例2：企業業績診断デスク](../performances/importdesk.md)で使う EDINET の MCP サーバーとは、ここが違います。

:::

## 設定情報をダウンロードする

次のファイルをダウンロードしてください。

**[補助金診断デスクの設定情報をダウンロード](https://github.com/gotoai/kari-release/releases/download/v0.7.4/grants.dsk)**

`.dsk` は、エージェントデスクの設定をひとまとめにしたファイルタイプです。このファイルには次のものが入っています。

| 入っているもの | 内容 |
| --- | --- |
| デスクの設定 | 表示名「補助金診断デスク」、デスク全体指示、使用する拡張機能（Python・Web Fetch）、ポート番号、成果物の送付方法 |
| リクエストフォーム | 「エージェントデスクデモ: 補助金診断依頼フォーム」 |
| スキル | 「補助金診断スキル」（補助金の探し方・絞り方・判断の目安と、レポートを PDF に組む `build_report.py`） |

**入っていないもの**は、AI プロバイダーの選択、Eメールアカウントとパスワード、管理者のEメールアドレス、そして MCP サーバーそのものです。これらはインポートした後に、この手順で設定します。

## インポートする

左のナビゲーションの「**エージェントデスク**」を右クリックし、「**設定情報によるエージェントデスクをインポート…**」を選びます。

![エージェントデスクの右クリックメニュー](@site/docs/current/main/agentdesk/img/agentdesks_desk_import.png)

<div className="caption">「設定情報によるエージェントデスクをインポート…」を選ぶ</div>

ファイル選択のダイアログで、ダウンロードした `grants.dsk` を選びます。読み込みが終わると、「**補助金診断デスク**」がエージェントデスクの一覧に追加されます。

インポートの直後に、設定が必要な項目を知らせるメッセージが表示されます。内容は次のとおりです。

> 起動する前に、設定でAIプロバイダーとモデル、送信Eメールアカウント、管理者の受信Eメールアドレス、MCPサーバーを確認してください。

:::note ポート番号が変わることがあります

このデスクは、Web インテークポータルに **8001**、成果物ダウンロードポータルに **18001**、モニターコンソールに **28001** を使います。いずれかがすでに他のデスクやアプリに使われている場合は、空いている番号に自動で移され、その旨がメッセージに表示されます。移された場合は、以降の手順で出てくるポート番号を読み替えてください。実際の番号は、デスクの設定の「一般」と「インバウンドチャンネル」で確認できます。

:::

次は、[MCP サーバーの設定](./setupmcpserver.md)に進みます。
