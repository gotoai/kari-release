# Eメールの設定

デスクは、診断レポートができたことを**依頼者**に知らせ、処理の節目を**管理者**に知らせるために、Eメールを送ります。設定するのは次の2つです。

| 設定 | 役割 |
| --- | --- |
| **常時受信Eメールアドレス** | 管理者が受け取るアドレス。登録は必須です |
| **送信Eメールアカウント** | デスクが送信に使うアカウント。SMTP で送信します |

どちらも設定しないと、デスクは起動しません。依頼を受け付けたのに、結果を誰にも届けられない状態を作らないためです。

:::info 手順は例1と同じです

設定の画面と手順は、どのデスクでも共通です。画面付きの手順は、[例1：補助金診断デスクの「Eメールの設定」](../grants/setupemails.md)を参照してください。このページでは、要点だけを挙げます。

:::

## 設定する場所

「**企業業績診断デスク**」を右クリックして「**設定…**」を開き、「**一般**」の「**Eメール通知**」まで下にスクロールします。設定が済んでいない項目には「（*設定未完了）」と表示されます。

## 要点

| 手順 | 内容 |
| --- | --- |
| **管理者のアドレスを登録する** | 「常時受信Eメールアドレスを設定」から、表示名とアドレスを入力します。受け取る種類は「イベント通知」と「レポートと成果物」から選びます。このデスクの既定では、イベント通知がオン、レポートと成果物がオフです |
| **送信用のアカウントを設定する** | 「送信Eメールアカウントを設定」から、**Gmail**（アプリパスワードが必要。先に2段階認証を有効にします）か、**その他のEメール**（SMTP サーバー名・ポート・暗号化を入力）を選びます |
| **テスト送信で確かめる** | 管理者のアドレス宛にテストメールが1通送られます。届かない場合は、[例1の「テスト送信で確かめる」](../grants/setupemails.md#テスト送信で確かめる)に、よくある原因を挙げています |
| **保存する** | 設定ウィンドウ右上の「保存」をクリックします |

:::caution 個人のアカウントは使わないでください

デスクは無人で動き続け、依頼者にメールを送ります。個人のアカウントではなく、**デスク専用のアカウント**を用意してください。

:::

:::note 依頼者への送付通知

**依頼者**には、管理者の設定とは関係なく、フォームに入力されたアドレスへ成果物の送付通知が届きます。このデスクは**Eメール添付**が有効なので、診断レポートの PDF もメールに添付されます。

また、リクエストフォームの**コード認証**（受信者Eメールアドレスの確認）も、ここで設定した送信アカウントから送られます。

:::
