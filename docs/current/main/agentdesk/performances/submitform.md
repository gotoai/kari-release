# 依頼の送信

ここからは**依頼者**の立場です。ブラウザで Web インテークポータルを開き、診断を依頼します。

## ポータルを開く

ブラウザで `http://localhost:8002` を開きます。デスクのリクエストフォームが表示されます。

![Web インテークポータル](@site/docs/current/main/agentdesk/img/agentdesks_request_portal_finance.png)

<div className="caption">Web インテークポータルに表示されたリクエストフォーム</div>

フォームの先頭には、依頼者に読んでもらう2つの説明があります。

| 見出し | 内容 |
| --- | --- |
| **留意事項（重要）** | 回答を生成する AI が海外のサーバー上で動作する可能性があり、送信内容が海外のサーバーに記録される場合があること。**機密情報は入力しないこと** |
| **ご留意ください（診断の性質と出典）** | 本診断は分析であって投資の推奨ではないこと。出典が EDINET であり、PDL1.0 のもとで GotoAI が加工していること |

これらは、リクエストフォームの「**説明段落**」という項目で作られています。デスクを自社向けに作るときも、依頼者に先に伝えておきたいことはフォームに書けます。

:::note ポータルを開けるのはこのパソコンだけです

この構成では、ポータルは Kari が動いているパソコンからしか開けません。社内の別のパソコンや社外から依頼を受け付けるには、そのアドレスで応答するゲートウェイやリバースプロキシを別途用意します。

:::

## 分析対象の企業を選ぶ

「**分析対象企業**」は必須です。証券コードまたは企業名を入力すると、候補が絞り込まれます。

![企業を検索して選ぶ](@site/docs/current/main/agentdesk/img/agentdesks_request_finance_form_input1.png)

<div className="caption">「本田」と入力して候補から選ぶ</div>

候補は `7267 本田技研工業株式会社` のように、**証券コードと企業名**の形で表示されます。一覧から選んでください。自由入力はできません。

:::tip なぜ一覧から選ばせるのか

企業名は表記の揺れが大きく（「本田技研工業」「ホンダ」「HONDA」）、自由入力にすると、デスクが企業を特定できずに失敗します。一覧から選ばせれば、依頼の時点で証券コードが確定します。

**処理の途中で問い返さない**デスクでは、こうした「取り違えようのない入力」をフォームで用意しておくことが、そのまま成功率になります。

:::

## 比較企業を選ぶ

「**比較企業1**」から「**比較企業5**」は任意です。同じように検索して選びます。

![比較企業を選んだ状態](@site/docs/current/main/agentdesk/img/agentdesks_request_finance_form_input2.png)

<div className="caption">対象企業と5社の比較企業を選んだ状態</div>

ここでは次のように入力しています。

| 項目 | 入力値 |
| --- | --- |
| 分析対象企業 | 7267 本田技研工業株式会社 |
| 比較企業1〜5 | 7203 トヨタ自動車／7201 日産自動車／7211 三菱自動車工業／7270 SUBARU／7202 いすゞ自動車 |

**5社に満たない場合は、デスクが残りを自動で選びます。** 1社も入力しなければ、5社すべてを同業候補から選びます。自動で選ばれた企業が競合として不自然な場合（同じグループの会社など）は、デスクが入れ替え、その理由をレポートに書きます。

## 受信者Eメールアドレスを入力する

「**受信者Eメールアドレス**」は必須です。診断レポートの送付通知は、このアドレスに届きます。

このフォームには**コード認証**が付いています。

1. アドレスを入力し、「**認証コードを送信**」をクリックします。
2. そのアドレスに6桁のコードが届きます。有効期限は10分です。
3. 届いたコードを入力すると「認証しました。」と表示されます。

コードの認証を済ませないと、依頼を送信できません。存在しないアドレスや、他人のアドレスへ結果が送られることを防ぐためです。

:::note

認証コードは、[Eメールの設定](./setupemails.md)で設定した**送信Eメールアカウント**から送られます。コードが届かない場合は、そのアカウントの設定を確認してください。

:::

## 送信する

フォームの末尾にある「**送信**」をクリックします。入力に不備があれば、その場で項目ごとに指摘されます。この時点ではまだ依頼は作られません。

受け付けられると、「**ご依頼を受け付けました**」の画面に変わります（画面は[例1：補助金診断デスクの「送信する」](../grants/submitform.md#送信する)を参照してください）。

これで依頼がキューに入り、デスクが処理を始めます。依頼者は画面を開いたまま待つ必要はありません。**結果はEメールで届きます。**

次は、[結果の確認](./checkresult.md)に進みます。
