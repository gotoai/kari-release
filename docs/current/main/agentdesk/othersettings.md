# その他設定

このページでは、設定ウィンドウの残り項目を説明します。デスクの基本設定と稼働条件については、[一般設定](./generalsettings.md)を参照してください。

## AI プロバイダー

このデスクが考えるのに使う **AI プロバイダー・モデル・思考レベル**を選びます。Kari 本体で使っているものとは別に、**デスクごとに**設定します。

選べるのは、Kari 側で設定済みのプロバイダーだけです。Kari 本体でオフにしているプロバイダーも、デスクには選べます。本体のオン・オフは本体のチャット用のもので、デスクは別の仕事を持つ別のエージェントだからです。

:::caution サブスクリプションは選べません

デスクは人が付かないまま依頼を処理し続けるため、**API キー方式のプロバイダーだけ**を選べます。個人向けの Claude / ChatGPT のサブスクリプションは選択肢に現れず、デスクのプロセスも受け付けません。

:::

## インバウンドチャンネル

業務依頼が届く経路です。現在は **Web インテークポータル**（ブラウザから[リクエストフォーム](./requestform.md)で受け付けるページ）があります。

- **タイトル**：ポータルの上部に表示されます。空欄のときは表示名を使います。
- **ポート番号**：デスクごとに別の番号が必要です（1024〜65535、既定は 8001 から）。「ポート使用をテスト」で、その番号がこのパソコンで使えるかを確かめられます。
- **認証情報**：有効にすると、フォームを表示する前にユーザー名とパスワードを確認します。パスワードはデスクのフォルダーには保存されないため、フォルダーをコピーしても一緒にコピーされません。

ポータルは、このパソコンからのみ開けます。社内の他のパソコンや社外から開くには、このアドレスで応答するゲートウェイやリバースプロキシを別途用意してください。

## 拡張機能

デスクに持たせる Kari の拡張機能です。依頼の処理で使わないものはオフにしておきます。

| 拡張機能 | できること |
| --- | --- |
| **Python** | 表計算・文書・PDF の処理や分析、グラフ作成を Python で実行します。Kari に同梱のインタープリタを使うため、インストールは不要です |
| **Web Fetch** | インターネット上の Web ページや PDF をテキストとして読み取ります。Python 拡張機能の上で動作するため、**Python はオンのままにしてください** |

拡張機能は Kari が標準で備えるツールです。業務に固有のデータ源や外部システムは、[MCP サーバー](./mcpservers.md)として与えます。

:::caution

**依頼の処理で使わない拡張機能はオフにしてください。** 使える道具が多いほど、エージェントが誤った道具を選ぶ余地が増えます。

:::

## デスクスケジューラー

[業務終了時コマンド](./generalsettings.md#受付時間と業務終了時コマンド)が「その日の処理が終わってから」実行されるのに対し、**デスクスケジューラー**は**実行する時刻が決まっている作業**を実行します。例えば、受付開始前に GPU サーバーを起動するなどコマンドを実行します。

- スケジュールは5フィールドの crontab 形式で、**JST** で解釈します（分・時・日・月・曜日）。曜日は0が日曜です。`30 8 * * 1-5` なら月曜から金曜の8時30分です。
- 実行項目ごとに名前・コマンド・制限時間（秒）を指定します。名前は、ログや通知でそのエントリーを指すために使います。
- **実行項目はデスクの稼働中にのみ実行されます。** デスクが停止するとスケジューラーは作動しません。
- コマンドに API キーなどの資格情報を直接書かず、**スクリプト名を指定して、資格情報はスクリプトの中で扱ってください。** コマンドは設定ファイルにそのまま保存されますので、資格情報を漏洩しないように留意する必要があります。
