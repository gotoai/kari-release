# Kari の AI エージェントで、国籍・地域別で消費総額試算値のトレンドの可視化と示唆出しを自動化させる

:::info 検証環境

本事例の手順は、以下の環境で動作を確認しています。

- **Kari**: バージョン 0.7.3 Windows
- **AI プロバイダー**: Anthropic Claude サブスクリプション
- **モデル**: Claude Opus 5.5 High

:::

## 説明

前のページで、来訪者数の推移を見ました。次に知りたいのはいくら使われたか、つまり**消費総額**です。手元にあるのは次の3つだけです。

| データ | 出所 | 粒度 |
| --- | --- | --- |
| 費目ごとの**購入者単価** | インバウンド消費動向調査 | 四半期 |
| 費目ごとの**購入率** | インバウンド消費動向調査 | 四半期 |
| **来訪者数** | 訪日外客統計 | 月 |

この3つから、次の式で**試算**します。

```
1人あたり支出 ＝ Σ（費目の購入者単価 × 購入率）
消費総額試算値 ＝ 1人あたり支出 × 来訪者数
```

「購入者単価」は**買った人の平均額**なので、そのままでは全員の平均になりません。**購入率を掛けて**、来訪者1人あたりの期待支出になります。これを6費目分足し合わせ、来訪者数を掛けたものが消費総額の試算値です。

ちなみに、前のページで作ったファクトテーブルは、**この計算のために設計されていました。** キー（国籍・地域 × 年月）がそろい、単価・購入率・来訪者数が同じ行に並んでいるため、掛け算と足し算だけで試算値が出ます。

:::caution これは「試算値」であって公表値ではありません

購入者単価と購入率は**四半期の値**を月に複製したものです（[結合処理のページ](/aidataanalysis/inboundconsumption/joindata)を参照）。したがって、この試算値の**月次の変動は、来訪者数の変動のみに由来します。**

また調査は標本調査であり、ここで得られる金額は**観光庁が公表する消費額とは一致しません。** 本ページの数字は、あくまで Kari の動作例として算出した試算値です。

:::

## AI に作業を指示

- 計算式、期間、除外条件、チャート、示唆出しまでをまとめて指示します。

```text title="AI への指示"
データフロー「データコレクション2:インバウンドファクトデータ」を用い、インバウンド購入の推移を分析して可視化する。

1. 2024年1月から最新月までにする。
2. 購入率の欠損値ありの月の数が全体の半分以上の国籍・地域のキーを除外する。
3. 月別、国籍・地域別の購入金額試算値を下記の手順で算出する。
  (1) 月別、国籍・地域別で、費目ごとに 「購入者単価」 × 「購入率」を 計算し、さらに足し合わせをして 「購入者単価試算値」 とする。
  (2) 月別、国籍・地域別で、 「購入者単価試算値」 x 「来訪者数」 を計算し、結果を 「消費総額試算値」 とする
4. 月別、国籍・地域別のを「消費総額試算値」をデータフロー「インバウンド消費総額試算値月推移」として保存する。
5. 月を横軸とし、積み上げ縦棒グラフを作成する。
6. データフロー「インバウンド来訪者数月推移」、「インバウンド消費総額試算値月推移」をもとに、消費総額試算値の増減が著しい国籍・地域を分析したうえ、トレンド、得られる示唆などをまとめてチャットで出力する。
```

![AI に消費総額試算値の分析を指示する](@site/docs/current/main/aidataanalysis/img/inbound_consumptiontrend_chatprompt.png)

この指示の組み立て方には、次のポイントがあります。

| 指示のブロック | ねらい |
| --- | --- |
| 3-(1) 計算式を分解して与える | 「消費額を出して」ではなく、**単価×購入率の合計**という中間値を定義させます。この一段を飛ばすと、購入者単価をそのまま足した過大な値が出ます。 |
| 3-(2) 来訪者数との掛け算 | 1人あたりの額に人数を掛けて総額にする、という順序を明示します。 |
| 4. 中間結果の保存 | 試算値を**データフローとして残させます。** 手順6でこれを読み直します。 |
| 6. 2つのデータフローを参照 | **来訪者数と消費額の両方**を読ませます。片方だけでは「客数が伸びたのに消費が伸びない」といった食い違いを見つけられません。 |
| 6. 増減が著しいキーの分析 | 全体の推移ではなく、**どの市場が動かしたか**を特定させます。 |

:::caution

**「購入者単価 × 購入率」という一段を指示に含めてください。** 購入者単価は「その費目を買った人の平均額」です。買わなかった人を含む全体の平均にするには、購入率を掛ける必要があります。この処理を指示しないと、**全員が全費目を買った前提の過大な金額**になります。

:::

## 作成されたチャートを確認する

![インバウンド消費総額試算値の月推移](@site/docs/current/main/aidataanalysis/img/inbound_consumptiontrend_chart.png)

データフロー「インバウンド消費総額試算値月推移」は **600行**。**20国籍・地域 × 30ヶ月** です。

前のページの来訪者数は32ヶ月（2026年8月まで）でしたが、こちらは**30ヶ月（2026年6月まで）**です。理由がノートに書かれています。

> 来訪者数は2026年8月まで公表されているが、**消費動向調査が四半期公表で遅行するため試算値は2026年6月で打ち切り。**

掛け算に使う2つのデータは、**公表のタイミングが違います。** 短いほうに合わせて打ち切るのが正しい処理です。ここを合わせないと、最後の2ヶ月だけ単価が古い四半期の値のまま延長されます。

もう1つ、部分的な除外も報告されています。

> **ロシアは2024年1-3月期の調査値が無く、同3か月は積み上げに含まれない。**

キーごと除外するのではなく、**値のない3ヶ月だけを落としています。**

:::tip 凡例の順序が、前のページと違います

積み上げ順・凡例順は「期間合計の多い順」です。前のページ（来訪者数）の先頭は **韓国・中国・台湾・米国・香港** でしたが、このページ（消費額）では **中国・台湾・米国・韓国・香港** に変わります。

**来る人が多い順と、使う金額が多い順は一致しません。** この違いが、以降の分析の主題になります。

:::

## AI の分析と示唆を読む

![AI による消費トレンドの分析（前半）](@site/docs/current/main/aidataanalysis/img/inbound_consumptiontrend_insight1.png)

AI の回答は **「分析：中国の急落が市場全体の伸びを打ち消した」** という見出しから始まります。

### 1. 市場全体は2026年に入って初めて減速

> 上期（1-6月）消費総額試算値：**2024年 33,388億円 → 2025年 41,176億円（+23.3%）→ 2026年 40,237億円（-2.3%）**。来訪者数も同じく -2.7%。2年前比では依然 +20.5% です。

前のページと同じく、**3年とも1-6月にそろえて**比較しています。

### 2. 反転の原因はほぼ単一市場

> 中国の上期消費総額試算値は 11,009億円 → 5,419億円（**-50.8%、-5,590億円**）、消費シェアは 2024年 25.4% → 2026年 13.5% に半減しました。
>
> **中国を除けば、2025→2026年上期は消費 +15.4%・客数 +13.5% と二桁成長が続いています。** 市場全体の -2.3% は「インバウンドの失速」ではなく「中国の消失」です。

前のページの来訪者数でも同じ構造が報告されていました。**消費額で見ても結論は変わりません。**

### 3. 要因分解

ここが、このページでいちばん価値のある分析です。上期の **-939億円** を3つの効果に分けています。

| 効果 | 寄与 |
| --- | --- |
| 客数効果（総客数の減少） | **-1,129億円** |
| 構成効果（国籍ミックスの変化） | **-1,672億円** |
| 単価効果（各国の1人あたり支出上昇） | **+1,863億円** |

> 単価上昇が客数減をほぼ補ったものの、**構成効果のマイナスが最大**です。客数シェアで中国（1人あたり26.3万円＝平均の1.3倍）が23.2%→10.4%へ落ち、代わりに韓国（9.5万円＝平均の0.47倍）が23.5%→28.7%、台湾（16.9万円）が16.2%→20.1%へ拡大しました。**「高単価客が減り、低単価客が増える」入れ替わり**が起きており、市場全体の1人あたり支出は 202,506円 → 203,468円（+0.5%）とほぼ横ばいに留まっています。

**前のページの結論が、ここで修正されます。** 来訪者数だけを見れば「韓国・台湾が中国の穴を埋めた」でした。しかし消費額で見ると、**埋めたのは人数であって金額ではありません。** 1人あたり26.3万円の客が減り、9.5万円の客が増えたからです。

総数と平均単価だけを見ていると、この入れ替わりは見えません。**1人あたり支出が +0.5% でほぼ横ばい**という結果は、単価が上がった効果と、構成が悪化した効果が打ち消し合った結果です。

### 4. 伸びているキー

![AI による消費トレンドの分析（後半）](@site/docs/current/main/aidataanalysis/img/inbound_consumptiontrend_insight2.png)

2024→2026年上期の増減額順に並べた表です。

| 国籍・地域 | 消費増減額 | 消費24→26 | 客数24→26 | 1人あたり24→26 |
| --- | --- | --- | --- | --- |
| 台湾 | **+2,406億円** | +55.9% | +33.3% | +16.9% |
| 米国 | **+2,029億円** | +48.8% | +35.7% | +9.7% |
| 韓国 | +1,194億円 | +28.3% | +27.8% | **+0.4%** |
| オーストラリア | +700億円 | +46.3% | +28.4% | +13.9% |
| タイ | +447億円 | +45.2% | +13.9% | **+27.4%** |
| 英国 | +385億円 | +53.9% | +31.2% | +17.3% |
| ベトナム | +371億円 | +56.9% | +19.5% | **+31.3%** |
| ドイツ | +367億円 | +78.9% | +38.3% | **+29.4%** |
| 中国 | **-3,070億円** | -36.2% | -33.0% | -4.7% |
| 香港 | -375億円 | -11.9% | +1.8% | **-13.4%** |

この表の読みどころは、**「客数」と「1人あたり」の列が独立して動いている**ことです。AI も4つの型に整理しています。

> - **台湾**は客数・単価がともに伸びる最良のパターンで、2026年Q1に3,451億円と中国（2,784億円）を抜いて最大市場になりました。
> - **韓国は客数だけが伸び、単価は0.4%で据え置き**（1人あたり9.5万円、20キー中最低）。2026年上期は客数 +18.6% と最も伸びましたが、消費は +11.4% にしか結びついていません。
> - **タイ・ベトナム・ドイツ・ロシアは単価が3割前後上昇**。ロシアは…シェアは0.9%で全体への寄与は限定的です。
> - **香港が唯一「客数横ばい・単価下落」**（-13.4%）。客数は維持しているのに消費が減る、**質的な劣化**が出ている市場です。
> - **インドは客数 +72.5%（最大の伸び率）に対し単価 -12.1%**。拡大しているが低単価化しています。

前のページで「伸び率が高い」と紹介されたインドは、**消費額で見ると低単価化**しています。香港にいたっては、客数が増えているのに消費が減っています。**来訪者数の分析だけで市場を評価してはいけない**ことが、具体的な数字で示されています。

## Human-in-the-loop のポイント

AI に任せきりにせず、次の点は人が確認してください。

- **報告された数字を検算する**  
本例では、主要な数字はすべて整合していました。上期の 33,388 → 41,176 → 40,237 は +23.3% / -2.3% / 2年前比 +20.5% と一致し、要因分解の -1,129 − 1,672 + 1,863 = -938 も報告の -939億円（端数処理）と合います。

    ただし**1箇所だけ合いません。** 「台湾・米国が中国の穴の**7割強**を埋めた（+4,435億円 vs 中国 -3,070億円）」という記述は、括弧内の数字で計算すると **144%** になります。2025→2026年上期の中国の減少（-5,590億円）と比べれば **79%** で「7割強」と整合するため、**本文と括弧で比較している期間が違っている**可能性があります。**文章の表現と、添えられた数字が食い違うことはあります。**

- **月次の変動は来訪者数しか反映していない**  
単価・購入率は四半期の値を月に複製したものです。チャートの月ごとの凹凸は、**人数の増減だけで説明されます。** 「この月に単価が上がった」とは読めません。

- **公表のタイミングが違うデータを掛けていることを意識する**  
来訪者数は8月まで、消費動向調査は6月までです。本例では短いほうに打ち切られていますが、**打ち切りが行われているかを必ず確認してください。** 延長されていると、直近の数字が古い単価のまま人数だけ動いた値になります。

- **「客数」と「1人あたり」を分けて見る**  
韓国は客数 +18.6% で最大の伸びですが、消費は +11.4% にとどまります。香港は客数 +1.8% なのに消費は -11.9% です。**客数の順位と消費の順位は一致しません。**

- **構成効果を見落とさない**  
総数と平均単価だけを見ると、市場の質的な変化は見えません。本例では1人あたり支出が +0.5% とほぼ横ばいですが、その内側で**高単価客から低単価客への入れ替わり**が起きています。

- **試算値を公表値として扱わない**  
標本調査の値から計算した推計です。観光庁が公表する消費額とは一致しません。対外的に用いる場合は、**算出方法と前提を必ず併記**してください。

- **除外・欠落の範囲を確認する**  
メキシコはキーごと除外、ロシアは2024年1-3月の3ヶ月だけが欠落しています。**キー単位の除外と、期間単位の欠落が混在**しています。

:::caution

使用する LLM により、要因分解の手法や着目する市場が変わります。**特に分解の定義（客数効果・構成効果・単価効果をどう計算したか）は結果を大きく左右します。** データフローのスクリプトで実際の計算を確認してください。

:::
