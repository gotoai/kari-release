# Kari の AI エージェントで、国籍・地域別で消費総額試算値のトレンドの可視化と示唆出しを自動化させる

:::info 検証環境

本事例の手順は、以下の環境で動作を確認しています。

- **Kari**: バージョン 0.7.3 Windows
- **AI プロバイダー**: Anthropic Claude サブスクリプション
- **モデル**: Claude Opus 5.5 High

:::

## 説明

前のページで、来訪者数の推移を見ました。次に知りたいのはいくら使われたか、つまり**消費総額**です。手元にあるのは次の2つです。

| データ | 出所 | 粒度 |
| --- | --- | --- |
| **1人あたり旅行支出** | インバウンド消費動向調査「参考2」 | 四半期 |
| **一般客数** | 訪日外客統計 − 出入国管理統計 | 月 |

この2つから、次の式で**試算**します。

```
消費総額試算値 ＝ 1人あたり旅行支出 × 一般客数
```

掛け算が1つだけです。前のページまでの準備——**粒度をそろえ、国名を名寄せし、クルーズ客を引く**——が済んでいるため、ここでの計算そのものは単純になります。**分析の難しさは、計算式ではなく準備にある**という、この事例全体の主題がそのまま現れています。

:::caution 単価を自分で組み立てさせないでください

消費動向調査のブックには、**1人あたりの金額を載せた表が複数あります。** どれを使うかで結果が1割変わります。

| シート | 内容 | 2026年4-6月期の全国籍 | 備考 |
| --- | --- | --- | --- |
| `表2-1` | 費目別の**購入率**と**購入者単価** | （掛け合わせて合計すると 222,119円） |  |
| `表3-1` | 1人1回当たり旅行消費単価 | 222,119円 |  |
| `参考2` | 同上（**パッケージツアー参加費内訳を含む**） | **244,733円** | 本事例で使用 |

`表2-1` の購入率と購入者単価を掛けて足し上げれば `表3-1` と一致しますが、**パッケージツアー参加費の国内分が落ちるため1割ほど低く出ます。** 観光庁の公表する消費総額が立脚しているのは `参考2` の系列です。

本事例では **`参考2` の「全体」の値をそのまま使います。** 自分で単価を合成する必要はありませんし、**合成すると別の系列になってしまいます。**

:::

ちなみに、前のページで作ったファクトテーブルは、**この計算のために設計されていました。** キー（国籍・地域 × 年月）がそろい、1人あたり旅行支出と一般客数が同じ行に並んでいるため、1列の掛け算で試算値が出ます。

:::caution これは「試算値」であって公表値ではありません

1人あたり旅行支出は**四半期の値**を月に複製したものです（[結合処理のページ](/aidataanalysis/inboundconsumption/joindata)を参照）。したがって、この試算値の**月次の変動は、一般客数の変動のみに由来します。**

また調査は標本調査であり、一般客数も「訪日外客数 − 船舶観光上陸許可数」で求めた近似です。ここで得られる金額は、**観光庁が公表する消費額とは一致しません。** 本ページの数字は、あくまで Kari の動作例として算出した試算値です。

:::

## AI に作業を指示

- 計算式、期間、除外条件、チャート、示唆出しまでをまとめて指示します。

```text title="AI への指示"
データフロー「データコレクション2:インバウンドファクトデータ」を用い、インバウンド消費総額の推移を分析して可視化する。

1. 2024年1月から、消費総額試算値が算出できる最新月までにする。
2. 1人あたり旅行支出の欠損値ありの月の数が全体の半分以上の国籍・地域のキーを除外する。
3. 月別、国籍・地域別で「1人あたり旅行支出」×「一般客数」を計算し、結果を「消費総額試算値」とする。
4. 月別、国籍・地域別の「消費総額試算値」をデータフロー「インバウンド消費総額試算値月推移」として保存する。
5. 月を横軸とし、積み上げ縦棒グラフを作成する。
6. データフロー「インバウンド来訪者数月推移」、「インバウンド消費総額試算値月推移」をもとに、消費総額試算値の増減が著しい国籍・地域を分析したうえ、トレンド、得られる示唆などをまとめてチャットで出力する。
```

![AI に消費総額試算値の分析を指示する](@site/docs/current/main/aidataanalysis/img/inbound_consumptiontrend_chatprompt.png)

この指示の組み立て方には、次のポイントがあります。

| 指示のブロック | ねらい |
| --- | --- |
| 1. 期間の指定 | ここでも**条件で**指定します。1人あたり旅行支出は2026年4-6月期まで、一般客数は2026年7月まで。**短いほうに合わせて打ち切らせます。** |
| 2. 欠損による除外 | 前のページと**同じ条件**にします。来訪者数の分析と消費額の分析で対象キーが違うと、2つのチャートを並べて読めません。 |
| 3. 計算式 | **掛け算を1つだけ**指定します。ファクトテーブルに「1人あたり旅行支出」が列として入っているため、ここで単価を組み立て直す必要はありません。 |
| 4. 中間結果の保存 | 試算値を**データフローとして残させます。** 手順6でこれを読み直します。 |
| 6. 2つのデータフローを参照 | **来訪者数と消費額の両方**を読ませます。片方だけでは「客数が伸びたのに消費が伸びない」といった食い違いを見つけられません。 |
| 6. 増減が著しいキーの分析 | 全体の推移ではなく、**どの市場が動かしたか**を特定させます。 |

:::caution

**手順6で2つのデータフローを参照させている**点が、このページの要です。消費額だけを読ませると「金額が増えた・減った」で終わります。来訪者数と並べることではじめて、**「人は増えたのに金額は増えていない」**という形の発見ができます。

:::

## 作成されたチャートを確認する

![インバウンド消費総額試算値の月推移](@site/docs/current/main/aidataanalysis/img/inbound_consumptiontrend_chart.png)

データフロー「インバウンド消費総額試算値月推移」は **600行**。**20国籍・地域 × 30ヶ月** です。縦軸の単位は**億円**になっています。

ノートが3段落あり、**計算式・対象範囲・読み方の制約**をそれぞれ書いています。

> 消費総額試算値 ＝ 1人あたり旅行支出（円/人, 観光庁 訪日外国人消費動向調査の四半期値を各月に展開）× 一般客数（人, 日本政府観光局 訪日外客数 − 船舶観光上陸許可者数）。
>
> 対象は2024年1月〜2026年6月の30か月。1人あたり旅行支出の欠損月が対象期間の半分以上を占めるメキシコは除外し、20の国籍・地域を積み上げた。**ロシアは2024年1〜3月期が非公表のため当該3か月分が積み上がっていない。**
>
> 四半期単価を月に展開しているため、**月次の変動は主に一般客数の変動を反映する。**

1段落目で**2つの出所をどう掛け合わせたか**が分かります。「訪日外客数 − 船舶観光上陸許可者数」という引き算まで式の中に書かれているため、チャート単体で定義が追えます。

前のページの来訪者数は31ヶ月（2026年7月まで）でしたが、こちらは**30ヶ月（2026年6月まで）**です。掛け算に使う2つのデータは、**公表のタイミングが違います。** 短いほうに合わせて打ち切るのが正しい処理で、指示1の「消費総額試算値が算出できる最新月まで」がこれを担保しています。

ロシアについては、キーごと除外するのではなく **値のない3ヶ月だけを落としています。** [Excel解析のページ](./parserawdata.md)で「ロシア2列は全43行が `-`」と報告されていた、あの欠損がここまで届いています。

3段落目は、**このチャートで言ってはいけないこと**をあらかじめ書いています。月ごとの凹凸を見て「この月は単価が上がった」とは読めません。

:::tip 凡例の順序が、前のページと違います

積み上げ順・凡例順は「期間合計の多い順」です。前のページ（来訪者数）の先頭は **韓国・台湾・中国・米国・香港** でしたが、このページ（消費額）では **中国・台湾・米国・韓国・香港** に変わります。

**来る人が多い順と、使う金額が多い順は一致しません。** 韓国は30ヶ月で最も多くの人が来た市場ですが、金額では4位です。この違いが、以降の分析の主題になります。

:::

## AI の分析と示唆を読む

![AI による消費トレンドの分析（前半）](@site/docs/current/main/aidataanalysis/img/inbound_consumptiontrend_insight1.png)

AI の回答は **「分析：消費総額試算値の増減が著しい国籍・地域」** という見出しで始まり、全体トレンド・4つの市場群・示唆という構成になっています。

### 全体トレンド：総額は頭打ち、しかし中身は総入れ替え

> 月別合計は2024年平均 約6,160億円 → 2025年 約7,100億円 → 2026年上期 約7,150億円。前年同月比は2025年前半の +16〜48% から急減速し、**2026年に入って −8.1%／+4.6%／+6.2%／−3.2%／+1.5%／−1.4% とほぼ横ばい〜微減**。直近12か月（2025年7月〜2026年6月）の合計は **84,468億円で前年同期比 +4.1%**（客数 +4.6%）。
>
> 総額が平らに見えるのは、**中国の崩落を台湾・米国・韓国の伸びがちょうど打ち消している**ためで、**安定ではなく相殺**です。

最後の一文が、このページ全体の結論です。**「変わっていない」と「何も起きていない」は違います。**

ここで AI は**直近12か月と前年同期**という比較軸を選んでいます。指示では期間の切り方を決めていません。この期間の取り方には理由があります。12か月は**四半期をちょうど4つ含む**ため、月に展開した単価の重みが均等になり、季節性も相殺されます。前のページ（来訪者数）が1-7月累計で比べていたのとは、別の選び方です。

:::tip 比較の期間は、分析の目的で変わります

同じデータでも、どの期間を切り出すかで見える絵が変わります。

| 比較期間の取り方 | 向いている問い |
| --- | --- |
| 暦年・上期などの**累計** | 「去年と比べてどうか」 |
| **直近12か月**と前年同期 | 「いま水準はどこにあるか」 |
| **前年同月比の並び** | 「変化はいつ起きたか」 |

AI はこの3つすべてを使い分けています。月別平均で水準を、前年同月比の並びで転換点を、直近12か月で現在地を示しました。**どれか1つだけでは、この3つは同時に言えません。**

:::

### 1. 中国 — 唯一かつ圧倒的な減少要因

| | 2025H1 | 2025H2 | 2026H1 |
| --- | --- | --- | --- |
| 消費総額試算値 | 10,403億円 | 9,338億円 | **5,366億円**（前年同期比 **−48.4%**） |
| 一般客数 | 414.7万人 | 386.0万人 | **201.6万人** |
| 月内構成比 | 約21〜25% | → | **10〜15%** |

> 月次で見ると断層は明確です。2025年8月 2,125億円（構成比 33.0%）→ 11月 1,213億 → **12月 778億（構成比 10.6%）** → 2026年以降は750〜1,000億円で横ばい。客数も 88.1万人（25年8月）→ 32.0万人（25年12月）→ 約30万人で定着。
>
> **単価ではなく客数の崩落**です（直近12か月の1人あたり旅行支出は −3.0% にすぎず、客数が −22.4%）。2025年11月を境に水準が切り替わり、半年以上戻っていないため、**一時的な谷ではなく新しい水準への移行**と読むべきです。

ここが、このページでいちばん価値のある分析です。**「いくら減ったか」ではなく「なぜ減ったか」を、単価と客数に分けて答えています。** 中国の単価は −3.0% しか落ちておらず、金額の半減はほぼ全部が人数です。

そして「**一時的な谷ではなく新しい水準への移行**」という判断には、**半年以上戻っていない**という観察が根拠として添えられています。グラフの形だけを見て「落ち込んでいる」と言うのではなく、**戻るかどうかを時間の長さで判定**しています。

### 2. 香港 — 静かな、しかし継続的な縮小

> 直近12か月 **−8.6%**（客数 −5.4%、単価 −3.3%）。構成比 8.9% → 6.8%（−2.1pt）。中国のような断層はなく、2025年半ばの月300〜450億円台への沈み込みが続いています。**客数と単価の両方がじわじわ落ちている**点が中国と異なり、こちらは**需要の構造的な弱さ**を示唆します。

中国と香港を**並べて対比させている**のが読みどころです。どちらも減っていますが、中国は「ある月を境に階段状に落ちた」、香港は「ずっと緩やかに落ち続けている」。**同じ『減少』でも、打ち手が変わります。**

積み上げチャートでは、どちらも「青い帯が薄くなった」としか見えません。**形の違いは、数字に戻らないと分かりません。**

### 3. 台湾・米国 — 中国を埋めた二本柱

![AI による消費トレンドの分析（後半）](@site/docs/current/main/aidataanalysis/img/inbound_consumptiontrend_insight2.png)

> - **台湾**: 直近12か月 +1,838億（+15.8%）、2026H1は 7,476億で**中国を抜いて最大市場**。客数 +18.3% に対し単価 −2.1%、つまり**完全に客数ドリブン**。
> - **米国**: +1,589億（+15.4%）。客数 +11.3% かつ**単価 +3.8%**（2026H1で 352,198円、主要国で最高水準）。2026年6月は 1,345億円で単月の構成比 20.4% に達し、**量と単価の両方で伸びている唯一の大型市場**。
> - **韓国**: 金額は +482億（+4.8%）と小さいが、客数は **+118.7万人（+13.0%）と台湾に匹敵**。**単価が −7.3%** と主要国で最も落ちており、**人数の伸びが金額に変換できていません**（1人あたり 101,646円は20市場で最低）。

**前のページの結論が、ここで修正されます。** 来訪者数だけを見れば、韓国は最大の市場で最大の伸びでした。しかし消費額では +4.8% にとどまり、**単価はむしろ下がっています。**

3市場とも伸びていますが、**伸び方の質が違います。** 米国だけが「量と単価の両方」です。同じ「成長市場」という言葉で括ると、この差は消えます。

### 4. 高単価・高成長の小規模市場

> いずれも規模は小さいが伸び率が際立ちます。**ベトナム +42.1%**（うち単価 +30.7% ＝ 全市場で最大の単価上昇）、**ロシア +61.2%**（客数 +48.6%）、**ドイツ +37.6%**、**インド +35.9%**、**インドネシア +30.4%**、**フランス・スペイン +28.2%**。欧州勢（英・独・仏・西）は客数・単価がそろって二桁で伸び、合計で **+1,310億円** — 香港の減少分（−531億）の2倍以上を稼いでいます。

小さい市場を個別に並べるだけで終わらず、**まとめると香港の減少分の2倍以上になる**という比較を添えています。「小さいから無視してよい」という結論を、**自分で否定している**箇所です。

### 得られる示唆

> 1. **中国依存からの脱却は「達成」ではなく「強制」された。** 2025年11月以降の中国の半減を他市場が吸収しきったのは幸運ですが、台湾・韓国の増分は客数の伸びに依存しており、単価はむしろ下がっています。中国が戻らない前提では、**次の総額成長エンジンが見当たりません。**
> 2. **注視すべきは台湾の一極集中リスク。** 中国 → 台湾へ首位が移っただけで、単一市場への依存度（2026年上期 17.4%）は解消していません。しかも台湾は中国（266,304円）より単価が低い（195,556円）ため、**同じ金額を稼ぐのにより多くの人数を要する＝受け入れ負荷が上がる**構造です。
> 3. **収益性で見れば打ち手は欧米豪・ベトナム。** 米国・豪州・英国・フランスは単価30〜43万円帯で、かつ単価が上昇中。**台湾1人分の金額を米国なら0.55人で稼げます。**
> 4. **韓国は「量は取れているが金にならない」。** 客数で全市場最大の増分（+118.7万人）を出しながら金額は +4.8%。滞在日数か費目構成に手を入れない限り、**人数増は総額にほとんど効きません。**

示唆2が、このページでもっとも実務的な指摘です。**「首位が中国から台湾へ移った」は、依存度が下がったことを意味しません。** しかも入れ替わった先のほうが単価が低いため、**同じ売上を得るのに必要な人数が増えます。** 宿泊施設や交通機関にとっては、売上が同じでも**負荷は増える**ということです。

示唆3の「台湾1人分を米国なら0.55人で」という言い換えも効いています。単価の差を**人数の比**に直すと、販促資源をどこに置くかの判断に直結します。

結論が「消費額が横ばいだった」ではなく、**次に何をすべきか**で終わっている点に注目してください。

## Human-in-the-loop のポイント

AI に任せきりにせず、次の点は人が確認してください。

- **報告された数字を検算する**  
本例では、主要な数字はほぼすべて再現できました。直近12か月の 84,468億円・前年同期比 +4.1%、中国の 2025年8月 2,125億円 → 12月 778億円、台湾 +1,838億（+15.8%）、米国の2026年6月 1,345億円などは、いずれもデータフローの値と一致します。

    ただし**1箇所だけ再現しません。** 「欧州勢（英・独・仏・西）は合計で **+1,310億円**」という記述は、同じ直近12か月の基準で計算すると **+1,509億円** になります。結論（「香港の減少分 −531億の2倍以上」）はどちらでも成り立ちますが、**合計値そのものは確かめ直す必要があります。** **文章の筋が通っていても、添えられた数字が合わないことはあります。**

- **欠落した月が、比較期間に含まれていないか確かめる**  
ロシアは2024年1-3月の3ヶ月分が積み上がっていません。本例の「直近12か月（2025年7月〜2026年6月）vs 前年同期」は**この3ヶ月を含まない**ため影響を受けませんが、**2024年前半を含む比較では効きます。** 3ヶ月と6ヶ月を比べることになり、見かけ上の伸びが過大になります。**比較期間と欠落期間が重なっていないか**を、そのつど確かめてください。

- **月次の変動は一般客数しか反映していない**  
1人あたり旅行支出は四半期の値を月に複製したものです。チャートの月ごとの凹凸は、**人数の増減だけで説明されます。** 「この月に単価が上がった」とは読めません。

- **公表のタイミングが違うデータを掛けていることを意識する**  
一般客数は7月まで、消費動向調査は6月までです。本例では短いほうに打ち切られていますが、**打ち切りが行われているかを必ず確認してください。** 延長されていると、直近の数字が古い単価のまま人数だけ動いた値になります。

- **「客数」と「1人あたり」を分けて見る**  
直近12か月で、韓国は客数 +13.0% と台湾に匹敵する伸びですが、単価が −7.3% のため金額は +4.8% にとどまります。香港は客数・単価がともに下がっています。**客数の順位と消費の順位は一致しません。**

- **「横ばい」を「変化なし」と読まない**  
市場全体は直近12か月で +4.1% ですが、その内側では中国が −4,812億円、台湾・米国が合わせて +3,427億円動いています。**大きな変化どうしが打ち消し合った結果の平坦さ**です。合計だけを見ていると、構成の入れ替わりを見落とします。

- **期間合計の順位と、直近の順位を区別する**  
チャートの積み上げ順は30ヶ月の合計なので、先頭は依然として中国です。しかし **2026年上期では台湾が最大市場**になっています。現在の市場規模を論じるときは、期間合計ではなく直近の値を見てください。

- **比較の期間がどこに取られたかを確認する**  
本例の AI は「直近12か月 vs 前年同期」を主軸にしました。前のページ（来訪者数）の「1-7月累計」とは別の期間です。**期間が違えば数字も変わります。** 2つのページの数字を並べる際は、**同じ期間で取り直して**ください。

- **試算値を公表値として扱わない**  
標本調査の単価に、近似で求めた人数を掛けた推計です。観光庁が公表する消費額とは一致しません。対外的に用いる場合は、**算出方法と前提を必ず併記**してください。

- **除外・欠落の範囲を確認する**  
メキシコはキーごと除外、ロシアは2024年1-3月の3ヶ月だけが欠落しています。**キー単位の除外と、期間単位の欠落が混在**しています。

:::caution

使用する LLM により、**比較の期間の取り方や着目する市場、分析の切り口そのものが変わります。** 同じ指示でも、要因分解を行う場合もあれば、市場群ごとの対比にまとめる場合もあります。**どの期間を、どう比べた数字なのか**を必ず読み取ってから、結論を引用してください。

:::
