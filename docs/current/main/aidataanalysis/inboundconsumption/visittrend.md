# Kari の AI エージェントで、国籍・地域別で来訪者数トレンドの可視化と示唆出しを自動化させる

:::info 検証環境

本事例の手順は、以下の環境で動作を確認しています。

- **Kari**: バージョン 0.7.3 Windows
- **AI プロバイダー**: Anthropic Claude サブスクリプション
- **モデル**: Claude Opus 5.5 High

:::

## 説明

前のページで、分析の土台となる**ファクトテーブル**ができました。ここからはデータ分析の本題に入ります。

最初に見るのは **来訪者数** です。**誰が、どれだけ来ているのか**を押さえておく分析です。

このページの作業には、2つのタスクがあります。

| | 内容 |
| --- | --- |
| **可視化** | 32ヶ月分の推移を、国籍・地域の積み上げで1枚のチャートにする |
| **示唆出し** | そのチャートの元データを AI 自身に読ませ、トレンドと示唆を言語化させる |

後者がこのページの要点です。チャートは「何が起きたか」を見せますが、**「それが何を意味するか」** という示唆出しは分析の真のアウトプットです。チャート作成も、示唆出しも、AI に任せられます。

:::tip このページの数字は「複製された値」ではありません

[前のページ](/aidataanalysis/inboundconsumption/joindata)で、四半期の支出データを月に複製したことに注意が必要だと述べました。

ただし **来訪者数は訪日外客統計そのままの月次データ**です。複製されていません。したがって、**来訪者数の月次推移は正しく分析できます。** 同じファクトテーブルでも、列によって使える粒度が違う点に注意してください。

:::

## AI に作業を指示

- 期間・除外条件・集計・チャート・示唆出しまでをまとめて指示します。

```text title="AI への指示"
データフロー「データコレクション2:インバウンドファクトデータ」を用い、インバウンド来訪者数の構成推移を分析して可視化する。

1. 2024年1月から最新月までにする。
2. 購入率の欠損値ありの月の数が全体の半分以上の国籍・地域のキーを除外する。
3. 月別の来訪者数推移を集計し、データフロー「インバウンド来訪者数月推移」として保存する。
4. 月を横軸とし、積み上げ縦棒グラフを作成する。
5. データフロー「インバウンド来訪者数月推移」をもとに、来訪者数のトレンド、得られる示唆などをまとめてチャットで出力する。
```

![AI に来訪者数の構成推移の分析を指示する](@site/docs/current/main/aidataanalysis/img/inbound_visittrend_chatprompt.png)

この指示の組み立て方には、次のポイントがあります。

| 指示のブロック | ねらい |
| --- | --- |
| 1. 期間の指定 | 「最新月まで」と相対で指定します。ファクトテーブルの終端（2026年8月）が自動的に使われます。 |
| 2. 欠損による除外 | **欠損の多いキーを機械的に落とします。** 全32ヶ月の半分以上で購入率が欠けている国籍・地域は、後続の消費額分析で使えません。**先に揃えておく**という判断です。 |
| 3. 集計結果をデータフローに保存 | チャートを描くだけでなく、**集計結果を残させます。** 次の手順5で AI がこれを読み直します。 |
| 4. チャートの形を指定 | 「月を横軸、積み上げ縦棒」と指定します。構成の推移を見るための形です。 |
| 5. トレンドと示唆の出力 | **ここがこのページの主目的です。** 作ったデータフローを AI 自身に読ませ、言語化させます。 |

:::caution

**手順3でデータフローに保存させてから、手順5でそれを読ませている**点に注目してください。チャートの画像だけを見て感想を述べさせるのではなく、**数値そのものを読み直させる**構成になっています。これにより、累計や構成比といった「チャートには描かれていない数字」まで扱えます。

:::

## 作成されたチャートを確認する

![インバウンド来訪者数の構成推移](@site/docs/current/main/aidataanalysis/img/inbound_visittrend_chart.png)

データフロー「インバウンド来訪者数月推移」は **640行**。2024年1月から2026年8月までの **32ヶ月 × 20国籍・地域** です。

チャートのノートに、除外の経緯が書かれています。

> インバウンド消費動向調査表2-1 の購入率が欠損している月が全32か月の半分以上を占めるキー（**メキシコ**）は除外し、**20の国籍・地域**を積み上げた。積み上げ順・凡例順は期間合計の多い順。

前のページのファクトテーブルは21国籍・地域でした。指示2によって**メキシコ1件が除外され、20件**になっています。**何件が、なぜ落ちたかが明示されている**ため、行数の差を追えます。

積み上げの順序が「期間合計の多い順」になっているため、**下から順に主要市場**が並びます。凡例の先頭は韓国・中国・台湾・米国・香港です。

## AI の分析と示唆を読む

![AI による来訪者数トレンドの分析と示唆](@site/docs/current/main/aidataanalysis/img/inbound_visittrend_insight.png)

AI の回答は5つの観察と、3つの示唆で構成されています。

### 1. 総数は2025年にピークを打ち、2026年は前年割れ

> 1-8月累計で **2,280万人（2024）→ 2,680万人（2025、+17.6%）→ 2,588万人（2026、−3.4%）**。（中略）**「伸び続ける市場」から「水準維持の市場」へ局面が変わった**と読めます。

2026年のデータは8月までしかありません。AI は**3年とも1-8月累計にそろえて**比較しています。年計で比べれば2026年だけが過小になるため、この処理は必須です。

### 2. 減速の原因はほぼ中国一国

ここが、このページでいちばん価値のある分析です。

> 2026年1-8月の中国は **290万人（前年同期 671万人、−56.7%）**。（中略）構成比は 25.0% → 11.2%（−8.9pt）です。
>
> **中国を除く19キーでは2026年1-8月は +14.4%** と二桁成長を維持しており、総数の前年割れは**需要全体の冷え込みではなく中国市場の断絶によるもの**です。

総数の **−3.4%** という見出しの数字だけを見れば「インバウンドは減速した」と読めます。しかし内訳を分解すると、**20市場のうち19市場は二桁成長**しており、1市場の急減が全体を押し下げているだけでした。**合計値が内訳を隠している**典型例です。

さらに、AI は自分で次の確認を促しています。

> 2025年11〜12月に非連続な水準変化があるため、**政策・運航要因の確認を推奨します。**

データの中で説明できないことを、**データの外に確認を投げている**点に注目してください。

### 3. 韓国・台湾が中国の穴を埋め、東アジア依存の中身が入れ替わった

> - **韓国**: 2026年1-8月 742万人（+21.2%）、構成比 **28.7%で最大**
> - **台湾**: 540万人（+19.8%）、構成比 20.9%
> - **香港**: 2025年は −7.1%と落ち込んだが2026年は +8.7%で回復
>
> 中国の縮小を韓国・台湾が吸収した形で、**1国依存リスクは中国から韓国へ移った**とも言えます。

構成が入れ替わっただけで、**集中の構造自体は変わっていない**という指摘です。チャートの見た目（高さがほぼ維持されている）からは読み取れない観察です。

### 4. 欧米・新興アジアは小さいが伸び率が高い

> インド（+20.2%）、ロシア（+22.1%）、マレーシア（+15.9%）…が2026年も二桁成長。米国は 230万人で構成比 8.9%（+1.2pt）と第4位を固めました。ただし**これら全体でもシェアは1〜2%台で、中国の−380万人を量で埋める規模には届きません。**

「成長市場が穴を埋める」という話を、**規模で検算して否定**しています。伸び率の高さと、量としての貢献は別だという整理です。

### 5. 季節性は明確で、月次の読み違いに注意

> 32か月平均では **10月（335万）・12月（339万）・4月（327万）が繁忙、9月（286万）・2月（304万）・8月（298万）が閑散**。（中略）直近8月の減少は季節要因も含むため、**水準判断は前年同月比で行うべき**です。

観察1で触れた「直近2026年8月は290万人」を、**季節性で割り引いて読むよう注意**しています。

### 示唆

> - 中国依存の収益計画は組み替えが必要で、**韓国・台湾（量）＋ 欧米・インド（単価）** の二軸が現実的な代替。構成比だけでなく、**同じファクトデータの購入者単価・購入率と掛け合わせた消費額ベースでの再評価が次の論点**です。
> - 韓国シェア28.7%は中国のピーク時（31.4%）に近く、**同じ集中リスクを再生産している**点は注視が必要です。
> - 9月・2月の閑散期と米国の3〜4月偏重を踏まえ、欧米・新興アジアの送客を閑散期に寄せる余地があります。

結論が「人数が減った」ではなく、**次に何を分析すべきか**で終わっている点に注目してください。1つ目の示唆が、そのまま次の消費額分析への導線になっています。

## Human-in-the-loop のポイント

AI に任せきりにせず、次の点は人が確認してください。

- **構成比は「20キーの中での」比率である**  
メキシコを除外し、さらにファクトテーブルの時点で合計行（総数・アジア計など）も落としています。したがって **「韓国28.7%」は訪日外客全体に対する比率ではありません。** 20の国籍・地域の合計を分母とした比率です。対外的に数字を引用する場合は、この分母を明示してください。

- **期間をそろえた比較になっているか確認する**  
2026年は8月までしかありません。本例では AI が3年とも1-8月累計にそろえていますが、**この処理が行われているかを必ず確認してください。** 年計同士で比べると、2026年だけが4ヶ月分少ない数字になります。

- **除外されたキーと、その理由を確認する**  
メキシコは「購入率の欠損が全32ヶ月の半分以上」という理由で落ちています。**来訪者数のデータは存在するのに、支出データの都合で除外されている**点に注意してください。来訪者数だけを見る分析であれば、除外しない選択もありえます。

- **非連続な変化は、データの外で裏を取る**  
AI は「2025年11〜12月に非連続な水準変化がある」と報告し、政策・運航要因の確認を推奨しています。**データだけでは原因は分かりません。** 報道や公表資料で裏付けを取ってから結論に用いてください。

- **伸び率と規模を混同しない**  
「ロシア +22.1%」と「中国 −56.7%」は、率としては同じ土俵に見えます。しかし実数では桁が違います。**率の高い市場が、量として代替になるとは限りません。**

- **季節性を考慮して水準を判断する**  
単月の増減には季節要因が含まれます。前年同月比で見るか、移動平均で均してください。

- **来訪者数以外の列には、別の制約がある**  
このファクトテーブルの支出属性は四半期の値を月に複製したものです。**来訪者数の分析がうまくいったからといって、同じ粒度で支出を論じることはできません。**

:::caution

使用する LLM により、着目する観点や示唆の深さが大きく変わります。**報告された数字は、必ずデータフローの値と突き合わせて確認してください。** 特に累計・構成比・前年同期比は、チャートには描かれていない計算結果です。

:::
