# 概要

:::info 検証環境

本事例の手順は、以下の環境で動作を確認しています。

- **Kari**: バージョン 0.7.3 Windows
- **AI プロバイダー**: OpenAI ChatGPT サブスクリプション
- **モデル**: GPT-6.1 Sol High

:::

## ユースケースの説明

ビジネスデータ分析の目的は、データから有用な情報を抽出し、意思決定に資する示唆を得ることです。しかし AI を使わない従来の進め方では、生データのクレンジング・整形・集計に大きな工数がかかります。しかも、仮説を組み替えるたびに、同じ処理をやり直すことになります。その結果、データを入手してから示唆を得るまでに長い時間を要することが少なくありません。

Kari の AI エージェントを活用すれば、生データの構造の解析、仮説に基づくデータ処理、そして結果の可視化までを一貫して任せられます。仮説を変更しても処理のやり直しが短時間で済むため、限られた時間の中で試行の回数を増やせます。本事例を通して、データ分析の生産性がどこまで上がるかを確かめてください。

## シナリオ

マイホームの購入、または不動産投資の観点から、東京都23区の不動産価格を分析します。検証する仮説は、たとえば次のようなものです。

- 不動産の価格は、どのような要素と相関するか
- 不動産の価格上昇率は、地域によってどのように違うか
- その上昇率は、人口密度などの環境要因と相関するか

従来であれば、こうした検証はデータ分析の専門家に依頼し、多くの作業時間を要するものでした。AI エージェントを活用すれば、同じ検証を自前で、しかも短時間で進められます。

## 本事例の進め方

本事例は、次の手順で進めます。

1. [国交省不動産情報ライブラリからデータを取得する](./retrievedata.md)

:::caution

本事例で扱うのは、実際の不動産取引価格のデータです。分析結果を購入や投資の判断に用いる場合は、**AI の出力した数値を必ず元データと突き合わせて確認してください。** 各ページの「Human-in-the-loop のポイント」に、確認すべき箇所を記載しています。

:::
