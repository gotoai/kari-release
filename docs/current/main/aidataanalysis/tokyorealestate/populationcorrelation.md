# Kari の AI エージェントで、中古マンション等の単位面積価格の上昇率と人口の増減率の相関を分析する

:::info 検証環境

本事例の手順は、以下の環境で動作を確認しています。

- **Kari**: バージョン 0.7.3 Windows
- **AI プロバイダー**: OpenAI ChatGPT サブスクリプション
- **モデル**: GPT-6.1 Sol High

:::

## 説明

前のページで、区ごと・条件ごとの価格上昇率 G を求めました。次にこういう質問は自然に出てきます。**「人が集まっている区ほど、価格が上がっているのではないか」**

これを確かめるには、**不動産データ以外のデータ**が必要となります。今まで使っている国交省の不動産データに人口情報は入っていません。東京都の統計から別途取得し、区市町村名で突き合わせて人口のデータを付け加えます。

本ページは、ここまでの事例と性格が違います。

| | ここまでのページ | このページ |
| --- | --- | --- |
| データ | 1つのファイルの中 | **2つの出所を結合** |
| 分析の単位 | 取引1件 | **区1つ（23点のみ）** |
| 問い | 何と一緒に動くか | **仮説が成り立つか** |

とくに重要なのが2行目です。**標本は23点しかありません。** 15万件を扱ってきた前ページまでとは、必要な慎重さがまったく違います。23点というスモールデータでの相関係数は、**1点動かすだけで簡単に変わります。**

このページでは、AI がその点をどう扱ったかが見どころになります。

## 東京都区市町村別人口データをダウンロードする

- まず人口データを用意します。東京都の統計ページから、直近5年分をまとめて取得させます。

```text title="AI への指示"
東京都の統計ページ「https://www.toukei.metro.tokyo.lg.jp/juukiy/2026/jy26000001.htm」を起点に、直近5年間の人口密度を含めた第1表をダウンロードし、ファイルを統合して現在のフォルダーで「東京都区市町村別人口.csv」として保存する。
```

![AI に東京都の人口データの取得を指示する](@site/docs/current/main/aidataanalysis/img/realestate_populationgrowth_downloadfile.png)

AI は Web ブラウザでページを開き、年度ごとに分かれた第1表を順に取得して、1つの CSV に統合します。処理の冒頭で、**xlsx スキルを読み込んで元表の構成を確認する**と宣言しているのが分かります。

:::tip 年度をまたぐ統合は指示に書く

東京都の統計は**年度ごとに別ページ・別ファイル**で公開されています。「直近5年間」とだけ書くと、年の特定からファイルの統合まで AI が判断します。**何年分を、どの単位で統合するか**を指示に含めておくと、取り違えが起きません。

[国交省不動産情報ライブラリからデータを取得する](./retrievedata.md)と同じく、アクセス間隔や中断条件を添えるとより安全です。

:::

## 東京都区市町村別人口のデータテーブルをAIで作成する

- 統合した CSV をデータコレクションに追加し、[AI 解析](./parserawdata.md)でテーブルにします。手順は不動産価格の CSV のときと同じです。

![AI による人口データの解析結果](@site/docs/current/main/aidataanalysis/img/realestate_populationgrowth_aiparseresult.png)

この例では、次のことが報告されています。

- **2022〜2026年の360行・18列**を読み込み、全列の型を確認。
- **欠損と「年×地域コード」の重複はなく、男女合計・人口前年差も一致。**

列の型の表を見ると、**「地域コード」が文字列**になっています。`13101` のような自治体コードを数値にしない判断で、[生CSVデータの解析](./parserawdata.md)のときと同じ判断です。

:::caution 集計行が混ざっています

人口データには **「地域階層」（0〜4）** という列があります。`0` が総数、`1` が区部・市部・町村部、`4` が個々の区市町村です。グリッドを見ると「総数」「区部」「市部」「郡部」「島部」「大島支庁」といった**集計行が混在**しています。

区ごとの比較をするなら、**階層4の行だけを使い、さらに23区に絞る**必要があります。集計行を混ぜたまま相関を取ると、合計値と個別値を同じ土俵に並べることになります。

:::

## 価格上昇率と人口増減率の相関を分析する

- 人口側と価格側でそれぞれ年平均の変化率を作り、区単位で突き合わせます。**検証の方法まで指示に含めている**のがこの指示の特徴です。

```text title="AI への指示"
中古マンション等単位面積価格の上昇率と、人口の増減率の相関性を分析する。

1. データテーブル「データコレクション1:東京都区市町村別人口.csv:テーブル1」をもとに、東京都区市町村別の通期の平均年人口増減率を計算し、新しい変数「平均人口年増減率」を追加してデータフロー「市区町村別人口増減率」を作成する。
2. データフロー「データコレクション1:中古マンション等単位価格上昇率セグメント」を参照し、「データコレクション1:不動産価格.csv:テーブル1」を用いて市区町村名別の通期での平均年中古マンション等単位価格上昇率を計算し、データーフロー「市区町村別中古マンション等単位価格上昇率」を作成する。
3. 市区町村別で、中古マンション等単位価格上昇率と、人口増減率、そして他の変数の変化率との相関を分析し、有意性と相関指標を算定してデータフロー「中古マンション等単位価格上昇率と人口増減率等の相関」に保存する。
4. 人口増減率と価格上昇率の散布図を作成する。
5. 作成したデータフローをもとに、中古マンション等単位価格上昇率と人口増減率等の相関を考察し、判定状況と示唆などをチャットで出力する。
```

![AI に人口増減率と価格上昇率の相関分析を指示する](@site/docs/current/main/aidataanalysis/img/realestate_populationgrowth_correlationprompt.png)

この指示の組み立て方には、次のポイントがあります。

| 指示のブロック | ねらい |
| --- | --- |
| 1-2. 両側を同じ形にそろえる | 人口も価格も「**通期の平均年変化率**」という同じ形に変換させます。片方が累計、片方が年率では比較できません。 |
| 2. 既存データフローの参照 | 前ページの「中古マンション等単位価格上昇率セグメント」を参照させ、**G の定義を引き継がせます。** 定義を書き直させると、前ページと数字が合わなくなります。 |
| 3. 他の変数も一緒に | 人口だけでなく**他の変数の変化率も同時に**分析させます。人口だけを調べると、人口が特別に効いて見えます。比較対象があってはじめて位置づけが分かります。 |
| 3. 有意性と相関指標 | 相関係数だけでなく **p 値や信頼区間まで**出させます。23点の相関は偶然でも簡単に出るため、これがないと判断できません。 |
| 4. 散布図 | 係数だけでは**どの点が効いているか**が分かりません。23点なら全部描けます。 |
| 5. 判定状況と示唆 | 「有意かどうか」の**判定**まで言わせます。数字を出させるだけでは、読む側に解釈が丸投げされます。 |

:::caution

**「有意性」を指示に含めてください。** 23点の相関係数は、関係がなくても 0.4 程度なら珍しくありません。p 値や信頼区間がないと、**0.6 という数字が強いのか弱いのか判断できません。**

:::

## 散布図で関係を見る

- 23区を1点ずつ描いた散布図です。

![東京都23区：人口増減率と中古マンション等単位価格上昇率](@site/docs/current/main/aidataanalysis/img/realestate_populationgrowth_scatter.png)

右上に **中央区**（人口増 約2.3%、価格上昇 約11.8%）が1点だけ突出しています。次が港区（約0.85%、約8.5%）、千代田区（約0.6%、約7.2%）。残りの20区は、人口増減率 0〜1%・価格上昇率 2〜6% の範囲に固まっています。

**左端に注目してください。** 渋谷区は人口増が **約0.03%** とほぼ横ばいなのに、価格上昇率は **約6.6%** で上から4番目です。人口が増えていなくても価格は上がっています。

チャートのノートに、検証の結果がそのまま書かれています。

> Pearson r=0.598、p=0.0026、Holm補正p=0.0256、95%CI 0.247〜0.811。Spearman ρ=0.324、p=0.131。**中央区を除くとr=0.162、p=0.472。人口増加と価格上昇の関係は中央区の影響が大きい。** 取引構成未調整・因果関係は示さない。

散布図を見てから数字を読むと、意味がはっきりします。**右上の1点を取り除くと、相関はほとんど消えます。**

## 検証の一覧を確認する

- データフローには、15通りの検証結果が並びます。

![相関検証の一覧データフロー](@site/docs/current/main/aidataanalysis/img/realestate_populationgrowth_correlationcriteria.png)

「分析区分」の列が **「通期・主分析」10件** と **「感度分析」5件** に分かれています。感度分析とは、**条件を変えても結論が変わらないかを確かめる**ための再計算です。

主分析で目立つのは次の2つです。

| 比較変数 | 標本区数 | Pearson r | p 値 |
| --- | --- | --- | --- |
| 平均人口年増減率 | 23 | **0.598** | 0.0026 |
| 平均面積年変化率 | 23 | **−0.580** | 0.0037 |

世帯数（0.268）、取引時築年数（0.236）、建ぺい率（0.282）は p 値が大きく、駅距離（0.403）と容積率（0.431）も 0.05 を超えています。なお**建ぺい率と容積率は標本が19区**しかありません。

そして感度分析の5件が、このページの核心です。

| 感度分析 | 標本区数 | Pearson r | p 値 |
| --- | --- | --- | --- |
| 人口 × 価格中央値 | 23 | 0.673 | 0.00043 |
| 人口 × 価格トリムなし | 23 | 0.419 | 0.047 |
| 2022〜2025共通期間 | 23 | 0.594 | 0.0028 |
| 人口CAGR × 価格 | 23 | 0.597 | 0.0026 |
| **中央区除外** | **22** | **0.162** | **0.472** |

上の4つは条件を変えても 0.42〜0.67 の範囲に収まります。ところが**最後の1行だけ、値が 0.162 に落ち、有意でなくなります。** 1点を抜いただけです。

## AI の判定と考察

![AI による相関の判定と考察](@site/docs/current/main/aidataanalysis/img/realestate_populationgrowth_correlationanalysisresult.png)

AI の回答は、見出しから結論を述べています。

> **人口増減率と価格上昇率には正の相関がありますが、中央区の影響が大きく、頑健性には限界があります。**

そして判定を表にまとめています。

| 検証 | 相関係数 | p値・判定 |
| --- | --- | --- |
| Pearson相関（23区） | 0.598 | 0.0026：**有意** |
| 多重検定補正後 | 同上 | 0.0256：**有意** |
| Spearman順位相関 | 0.324 | 0.131：**非有意** |
| 中央区を除外（22区） | 0.162 | 0.472：**非有意** |
| 2022〜2025年に期間をそろえた分析 | 0.594 | 0.0028：**有意** |

**5つの検証のうち2つが「非有意」です。** 都合の良い結果だけを並べていません。

続く段落で、何が起きているかを具体的に説明しています。

> 人口のPearson相関の95%信頼区間は **0.247〜0.811**、単回帰のR²は **0.358** です。中央区は人口が年平均約2.31%、価格が約11.71%上昇し、**全体の相関を強く押し上げています。** 一方、渋谷区は人口増が約0.03%でも価格が約6.64%上昇しており、**人口増だけでは価格動向を説明できません。**

信頼区間が 0.247〜0.811 と非常に広いことも、23点という標本の小ささを物語っています。R²=0.358 は、価格上昇のばらつきのうち人口増減率で説明できるのが**約36%**という意味です。

そしてもう1つの発見が報告されます。

> 他の変数では、**平均取引面積の変化率が価格上昇率と負の相関**を示しました（Pearson −0.580、Spearman −0.757、両方とも補正後有意）。**小面積物件への取引構成の変化や、面積が単位価格の分母であることが関係している可能性があります。**

これは注意深い指摘です。Y＝取引価格÷**面積**ですから、**面積が分母に入っています。** 取引される物件が小さくなれば、価格が変わらなくても Y は上がります。相関の原因が、市場の動きではなく**計算式の構造**にある可能性を、AI 自身が挙げています。

最後に、適用範囲を限定しています。

> 人口増加率は地域比較の参考指標になりますが、価格上昇の判断には立地や取引物件の構成も併せて確認する必要があります。今回の価格データは23区に限られ、**品質を一定にした価格指数でもない**ため、**因果関係や東京都全域への一般化は示していません。**

## Human-in-the-loop のポイント

AI に任せきりにせず、次の点は人が確認してください。

- **標本が23点であることを忘れない**  
これがこのページで最も重要な点です。23点の相関係数は、**1点動かすだけで結論が変わります。** 実際、中央区を除いただけで r=0.598 が 0.162 になりました。15万件の分析と同じ感覚で「r=0.6 だから強い相関」と読んではいけません。信頼区間 0.247〜0.811 の広さが、推定の不確かさをそのまま表しています。

- **必ず散布図を見てから係数を読む**  
数値だけなら「r=0.598、p=0.0026」は説得力のある結果に見えます。しかし散布図を見れば、**右上に1点だけ離れている**ことが一目で分かります。23点なら全部描けます。**描けるものは描いてから判断してください。**

- **判定が割れていることを、割れたまま受け取る**  
Pearson は有意、Spearman は非有意。期間をそろえると有意、中央区を抜くと非有意。**どれか1つを選んで「有意だった」と報告するのは誤りです。** AI が5つ並べて見せているのは、結論が条件に依存していることを示すためです。

- **分母の構造を疑う**  
平均取引面積の変化率が −0.580 という強い負の相関を示しました。しかし Y＝価格÷面積である以上、**面積が小さくなれば Y は自動的に上がります。** これは市場の発見ではなく、指標の定義から来る関係かもしれません。[相関分析のページ](./pricecorrelation.md)で Y の材料（取引価格・面積）を除外したのと同じ注意が、ここでも必要です。

- **集計行を混ぜない**  
人口データには「総数」「区部」「市部」「島部」などの集計行が含まれます。**階層4の個別区市町村だけを使っているか**を確認してください。合計値を1点として混ぜると、相関は簡単に強く出ます。

- **標本数の違う行を並べて読まない**  
建ぺい率・容積率の検証は**19区**、他は23区です。同じ表に並んでいても、母数が違います。

- **相関を因果と読み替えない**  
「人口が増えたから価格が上がった」とも「価格が上がる地域に人が集まった」とも、このデータからは言えません。どちらも同じ第三の要因（再開発など）の結果かもしれません。中央区の人口増と価格上昇が同時に起きているのは、**臨海部の大規模開発という共通の背景**を想起させますが、それはこのデータが示したことではなく、**次に確かめるべき仮説**です。

:::caution

使用する LLM により、実施される検証の種類（感度分析の有無、多重検定補正の方法）が変わります。**「有意だった」という報告を受け取ったら、何を何通り試したうえでの有意なのか**を必ず確認してください。

:::
