# バイブコーディングでアプリケーションを開発する

:::info 検証環境

本ページの手順は、以下の環境で動作を確認しています。

- **Kari**: バージョン 0.6.0 macOS
- **AI プロバイダー**: Anthropic Claude サブスクリプション
- **LLM**: Anthropic Opus 5 (1M)

:::

Kari を活用し、作りたいものの意図と仕様を自然言語で伝えるだけで、AI にソースコードを書かせてアプリケーションを開発できます。ユーザーはコードを書かず、AI が作成したソースコードと動作結果を確認する役割になります。このような開発の進め方を「バイブコーディング（Vibe Coding）」と呼びます。

## シナリオ

Web メールのデモアプリケーションを開発します。ログイン・メール一覧・メール詳細の3画面を持ち、Python と FastAPI、Jinja2 を使って、ローカル PC のブラウザーで動作を確認できるものです。

## インプット情報を確認

- ソースコードの出力先となる空のフォルダー「webmail_demo」を用意します。Kari の「エクスプローラー」からそのフォルダーへ移動し、フォルダーを開いておきます。AI は、開いているフォルダーを作業場所として扱います。

![ソースコードの出力先フォルダーをエクスプローラーで開く](@site/docs/current/main/usekari/img/usekari_vibecodinginput.png)

## AI に作業を指示

- 画面の流れ、データの件数と期間、ページング、使用する技術スタックを指定して、以下のように AI に作業内容を指示します。

```text title="AI への指示"
今開いているフォルダー「webmail_demo」の配下に、ソースコードツリーを作ってください。

1. Web メールアプリのデモです。ログインページ → メール一覧ページ → メールをクリックすると詳細ページ、という画面遷移にしてください。
2. 一覧は、実行時のシステム現在日付から直近30日の、約100通のメールを表示してください。
3. 一覧はページングし、1ページに20通のメールを表示してください。
4. 技術スタックは、Python + FastAPI + Jinja2 を使ってください。
```

![AI にソースコードの作成を指示する](@site/docs/current/main/usekari/img/usekari_vibecodinginstruction.png)

## AI の作業結果を確認

- AI は、必要なパッケージを Kari 同梱の Python 環境にインストールし、ソースコードとテストコードを作成したうえで、テストの実行とローカルサーバーの起動確認まで行います。進捗はセッションウィンドウに表示されます。

- 作業が終わると、作成されたファイルの構成がセッションウィンドウに表示されます。Kari の「エクスプローラー」でフォルダー「webmail_demo」を開き、ソースコードツリーが実際に作成されていることを確認します。

![AI が作成したソースコードツリー](@site/docs/current/main/usekari/img/usekari_vibecodingresulttree.png)

- フォルダー直下の `README.md` を開き、アプリケーションの仕様、パッケージのインストール手順、起動手順、ログイン用のアカウントを確認します。

![AI が作成した README.md](@site/docs/current/main/usekari/img/usekari_vibecodingresultreadme.png)

- `README.md` の手順に従ってアプリケーションを起動します。ターミナルでフォルダー「webmail_demo」へ移動し、以下を実行します（*お使いの環境のPythonを利用します*）。

```bash
python -m pip install -r requirements.txt
python run.py
```

- ブラウザーで `http://127.0.0.1:8000/` を開き、`README.md` に記載されたアカウントでログインします。

![デモアプリのログイン画面](@site/docs/current/main/usekari/img/usekari_vibecodinglogin.png)

- メール一覧画面で、直近30日のメールが1ページ20通ずつ表示され、ページングが動作することを確認します。

![デモアプリのメール一覧画面](@site/docs/current/main/usekari/img/usekari_vibecodingresultinbox.png)

- 一覧のメールをクリックし、詳細画面が表示されることを確認します。

![デモアプリのメール詳細画面](@site/docs/current/main/usekari/img/usekari_vibecodingresultdetail.png)

:::caution

- AI が生成するソースコードは、使用する LLM や実行のたびに、ファイル構成・実装方法・画面の体裁が変わります。本ページの画面キャプチャと同じ結果になるとは限りません。
- 本ページの例はデモアプリです。ログイン用のアカウントやセッションの秘密鍵がソースコードに直接書かれているなど、そのまま公開・業務利用できる作りにはなっていません。
- AI に依頼する際は、画面の流れ、データの件数と期間、技術スタックのように、確認できる形で条件を具体的に指定してください。条件があいまいなほど、意図と異なる実装になりやすくなります。
- 生成されたコードは、AI が実行したテストの結果だけで判断せず、実際に起動して動作を確認してください。

:::
