# ローカルの大量のファイルからコンテンツを検索する

:::info 検証環境

本ページの手順は、以下の環境で動作を確認しています。

- **Kari**: バージョン 0.5.0 Beta
- **AI プロバイダー**: スタンドアローン OumiGo (バージョン 0.3.0)
- **GPU モデル**: RTX A6000
- **LLM**: Meta Muse-Glimmer-30B (GotoAI により量子化済み、Hugging Face リポジトリ: `GotoAI-Inc/Muse-Glimmer-30B-W8A16`)

:::

Kari を活用し、AIによりローカルフォルダーにある大量のファイルの中身を読み取り、条件に合うコンテンツを検索・リストアップすることができます。ファイル名やキーワードによる検索ではなく、「発言者の感情が激しい文」のような意味による検索ができます。AI検索を高速化させるため、複数のサブエージェントを活用します。

## インプット情報を確認

- モーラバランス型日本語コーパス「ROHAN4600」の GitHub リポジトリを開きます。「Code」ボタンから「Download ZIP」でダウンロードして展開するか、`git clone` でローカルフォルダーへ複製します。  
URL: https://github.com/mmorise/rohan4600

- リポジトリには、4,600 文の日本語コーパスが同じ内容で複数の形式に収められています。本ページの手順では、このうち HTML、PDF、Word の3形式のファイルを検索対象にします。
  - `朗読者用_html`: HTML 形式
  - `朗読者用_PDF_h`、`朗読者用_PDF_v`: PDF 形式（横書き・縦書き）
  - `朗読者用_Word_h`、`朗読者用_Word_v`: Word 形式（横書き・縦書き）
  - `Rohan4600_transcript_utf8.txt`: 全文のテキスト

- Kari の「エクスプローラー」から展開したフォルダー「rohan4600」へナビゲートし、フォルダーを開いて中身を確認します。

![ROHAN4600 のフォルダーをエクスプローラーで確認](@site/docs/current/main/usekari/img/usekari_searchlocalfolderinput.png)

## AIに作業を指示

- 発言者の感情が激しいと思われる文を検索します。以下のようにAIに作業内容を指示します。

> フォルダー「rohan4600」の配下で、HTML、PDF、ワード形式のファイルを検索し、要件にコンテンツが該当するセンテンスを特定して必要な情報を出力してください  
> 
> 1. 入力情報  
> (1) ローカルフォルダー「rohan4600」の配下ファイル。  
>
> 2. 検索要件  
> (1) 検索対象は、フォルダー「rohan4600」の配下の全ての HTML、PDF、ワード形式のファイルです。  
> (2) 検索条件は、ファイルに含まれたセンテンスで、発言者の感情が激しいと思われるものです。  
> (3) 最大10個までサブエージェントを使っても良いです。  
> 
> 3. 出力情報には二つの部分があります。  
> (1) 検索概要：「ファイルタイプ」「ファイル検索数」「ファイル該当数」「センテンス検索数」「センテンス該当数」の5列、「HTML」「PDF」「ワード」の3行の集計表を出力してください。  
> (2) 該当センテンス一覧：「該当センテンス」「判定理由」「該当ファイルパス」の3列の一覧表を出力してください。  

![AIにフォルダー内の検索を指示する](@site/docs/current/main/usekari/img/usekari_searchlocalfolderinstruction.png)

## AIの作業結果を確認

- AIはフォルダー配下のファイルを形式ごとに読み取り、文単位で要件に照らして判定します。対象ファイルが多いため、作業には時間がかかります。進捗はセッションウィンドウに表示されます。

- 作業が終わると、検索概要の集計表と該当センテンスの一覧表がセッションウィンドウに表示されます。まず集計表で、3形式それぞれのファイル検索数がフォルダー内のファイル数と一致していること、センテンス検索数が形式間でおおむね揃っていることを確認します。

![AIが出力した検索概要と該当センテンス一覧](@site/docs/current/main/usekari/img/usekari_searchlocalfolderresultoverview.png)

![AIが出力した検索概要と該当センテンス一覧](@site/docs/current/main/usekari/img/usekari_searchlocalfolderresultdetails.png)

- 一覧の「該当ファイルパス」をいくつか選び、Kari の「エクスプローラー」からそのファイルを開いて、該当センテンスが実際に含まれていることと、判定理由が文の内容に合っていることを確認します。

:::caution

「感情が激しい」のような意味による判定は、使用するLLMにより結果が変わります。同じ文でも該当・非該当が分かれることがあるため、件数は目安として扱い、重要な判断には一覧の文を直接確認してください。また、ファイル数が多い場合、LLMによっては一部のファイルしか読まないことがあります。集計表のファイル検索数を実際のファイル数と照らし合わせてください。

:::
